# Iris Classification Case Study

## Project Overview

This project explores the **Iris dataset** provided by Scikit-learn.

It demonstrates basic dataset exploration using Python. The program loads the built-in Iris dataset and displays its contents, independent variables, dependent variables, and individual records with their corresponding target labels.

## Features

- Load the built-in Iris dataset using Scikit-learn.
- Display the complete dataset object.
- Display independent variable (feature) names.
- Display the number of independent variables.
- Display dependent variable (target class) names.
- Display the number of dependent variables.
- Display all dataset records.
- Show each record's ID, feature values, and target label.

## How to Run

Execute the Python file:

```bash
python iris_classification_case_study.py
```

## Dataset Information

The project uses the built-in Iris dataset available through `sklearn.datasets.load_iris()`.

The program displays:
- Dataset information.
- Feature names.
- Target class names.
- Feature values and target labels for all records.
